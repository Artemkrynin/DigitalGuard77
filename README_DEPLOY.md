# DigitalGuard — запуск на любом устройстве

## Локально
Backend:
```bash
cd backend
.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

## Публичный запуск
Проект подготовлен для Render. Он собирает React и затем раздаёт готовый frontend из FastAPI, поэтому пользователю нужен один публичный адрес.

1. Загрузите папку `DigitalGuard` в GitHub как репозиторий.
2. На Render выберите **New → Web Service** и подключите этот репозиторий.
3. Render автоматически прочитает `render.yaml`.
4. После Deploy откройте выданный адрес `https://...onrender.com`.

Важно: бесплатный Render подходит для школьной демонстрации, но сервис может засыпать после периода без запросов. В текущей версии используется SQLite. На бесплатном Render локальные файлы не являются постоянным хранилищем, поэтому аккаунты и результаты могут исчезнуть после перезапуска/переразвертывания. Не используйте реальные пароли или персональные данные.
